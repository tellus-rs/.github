**Actors for Rust, on solid ground.**

tellus is an actor framework for Rust, built on [Tokio](https://tokio.rs): typed messages,
supervision trees, death watch with an ordering guarantee and optional event-sourced persistence.

- [tellus.rs](https://tellus.rs): the website, with the getting started tutorial
- [tellus](https://github.com/tellus-rs/tellus): the repository
- [crates.io](https://crates.io/crates/tellus) and [docs.rs](https://docs.rs/tellus/latest/tellus/)
